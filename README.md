# 🖥️ CentOS Reminder

Одностраничная HTML-шпаргалка системного администратора для **CentOS / RHEL / AlmaLinux / Rocky Linux**.  
Работает локально, без бэкенда и зависимостей — просто откройте файл в браузере.

## ✨ Возможности

- 📁 Поиск и создание файлов и каталогов
- 💾 Поиск аномально крупных файлов и безопасное удаление
- 🐘 Проверка версий PHP и перезагрузка PHP-FPM (включая именованные сборки)
- 🌐 Nginx / Apache / Varnish / HAProxy — проверка и перезагрузка
- 🗄️ Перезагрузка MySQL / MariaDB / PostgreSQL / MongoDB / Redis
- 📊 Мониторинг нагрузки и зависших соединений (`ss`, `top`, `vmstat`, `iftop`)
- 🛡️ Настройка iptables и базовые правила безопасности
- 🚫 Установка и конфигурация fail2ban
- 📦 Экспорт: git, дампы БД, архивы, конфиги, логи
- 📋 Копирование команд в один клик (без комментариев)
